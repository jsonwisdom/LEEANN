LeahPrime kernel

No hidden accordions. Every module publishes its operating contract: input, output, current state, refusal boundary, and receipt rule.

Maxwell Gate

CLASSIFY

Classification gate. It sorts what arrived without pretending the sort itself proves truth.

InputRaw packet + declared class + source/provenance metadata.
OutputEVIDENCE_CANDIDATE · STORY · UNKNOWN_HOLD
Current stateClassification only. No adjudication power.
RefusesTruth declaration, authority creation, silent STORY → FACT promotion.
Receipt ruleThe assigned epistemic state travels with the packet into preservation.

BitBot

VERIFY BYTES

Byte verifier. It answers whether the preserved digital object matches the bytes or digest being checked.

InputArtifact bytes + byte count + declared digest/hash.
OutputMatch / mismatch + computed digest + byte count.
Current stateVERIFIED_BYTES is an evidence state, not a semantic verdict.
RefusesBiography, intent, meaning, identity, authorization, or truth inference.
Receipt ruleVERIFIED_BYTES ≠ AUTHORIZED

BoxD

PRESERVE

Original-preservation rail. It keeps the thing that actually arrived and appends receipts around it.

InputOriginal artifact + classification + provenance + digest.
OutputPreserved artifact + append-only receipt pointer + replay handle.
Current stateOriginal remains replayable from its preserved state.
RefusesSilent overwrite, retroactive rewriting, replacement-by-summary.
Receipt ruleNew information appends; prior state remains inspectable.

CrissCross

CHECK

Contradiction detector. It compares lanes without forcing incompatible records into fake agreement.

InputCompeting claims, receipts, prior states, and candidate-forward states.
OutputAgreement · conflict · dependency mismatch · unresolved gap.
Current stateContradictions remain visible until evidence actually resolves them.
RefusesAveraging away conflict or selecting the most convenient narrative.
Receipt ruleConflict is preserved as data, not deleted as noise.

Gray Baby

HOLD

Formal missingness state. It keeps the unanswered question inside the system instead of inventing a bridge.

InputMissing, ambiguous, conflicted, or insufficient evidence.
OutputUNKNOWN_HOLD + reason + required release condition.
Current stateGap stays replayable and visible in history.
RefusesGuessing, filling blanks, or converting uncertainty into confidence.
Receipt ruleRelease requires fresh evidence plus explicit reclassification.

Human Gate

TERMINAL

Terminal decision boundary. The machine can organize and explain; it does not grant itself permission.

InputEvidence states + story states + holds + receipts + replay path.
OutputHuman grant · reject · defer · request-more-evidence.
Current stateMachine authority remains false unless a valid external human grant exists.
RefusesSelf-promotion, silent authorization, command authority by inference.
Receipt ruleREPLAY ≠ AUTHORITY and RECEIPT ≠ AUTHORITY.
STORY ≠ FACTBYTE_MATCH ≠ TRUTHREAL_ENTITY ≠ EVENT_PROOFUNKNOWN → HOLDRECEIPT ≠ AUTHORITYHUMAN_GATE = TERMINAL
