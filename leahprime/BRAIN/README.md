## What BRAIN does

```text
QUESTION
→ SOURCE MAP
→ ALTERNATIVES
→ INVARIANT CHECK
→ EVIDENCE GAPS

→ TEACH-BACK

```

BRAIN is the active reasoning/specification lane.

- `story/` preserves historical narrative and provenance.
- `docs/public_record/` preserves source-bound real-person research.
- `receipts/` preserves receipts.
- `fixtures/` preserves test inputs.
- `leahprime/BRAIN/` develops bounded alternatives and reusable reasoning rules.

## Success definition

A BRAIN run succeeds when it makes the next human decision easier to understand, replay, and correct.
